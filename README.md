## 配套站点

`html/` 下为配套交互站点，直接用浏览器打开 `html/index.html` 即可：

- **首页** — 实测规格与完整目录（页码取自编译产物）
- **在线阅读** — 按真实目录定位章节，支持键盘方向键翻页
- **学习路线** — 按前置依赖排序的 10 章推进顺序，附进度勾选与三条备选路线
- **公式速查** — 麦克斯韦方程组、矢量恒等式、曲线坐标算子、基本常数
- **计算工具** — SI ⇄ 高斯单位换算、电磁波参数互算、矢量运算
- **勘误记录** — 本报告的数据化版本，可按范围与严重度筛选

站点的目录数据由 `tools/site/export_site_data.py` 从编译产物（`.toc` / `.aux`）
**自动生成**为 `html/book-data.js`，不手工维护，因此不会与教材正文脱节：

```bash
# 重新编译教材后，刷新站点目录数据
python tools/site/export_site_data.py
python tools/audit/verify_site.py     # 校验链接与资源完整性
```

## 使用建议

- 本书适用于具备**大学基础物理**和**多元微积分**知识的自学者
- 建议按章节顺序阅读，不可跳过静电学和静磁学
- 每道例题建议先独立尝试，再看解答
- 第 1 章是全书地基，其中的矢量分析与曲线坐标系贯穿后续所有章节
