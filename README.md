## 内容概览

本书共 **10 章**，涵盖：

1. **数学预备知识** — 矢量分析、梯度/散度/旋度、积分定理、δ 函数
2. **静电学基础** — 库仑定律、电场、电势、高斯定理
3. **电介质与静电边界条件** — 极化、D 场、边界条件
4. **静电学边值问题** — 镜像法、分离变量、多极展开
5. **静磁学** — 毕奥-萨伐尔定律、安培环路定理、磁矢势
6. **磁介质** — 磁化、H 场、磁学边界条件
7. **麦克斯韦方程组** — 法拉第定律、位移电流、电磁势、规范变换
8. **电磁波的传播** — 平面波、反射折射、波导、色散
9. **电磁波的辐射** — 推迟势、电偶极辐射、磁偶极辐射
10. **相对论电动力学** — 四维张量、电磁场张量、协变方程
