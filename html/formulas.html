矢量恒等式（附录 A）

A·(B×C) = B·(C×A) = C·(A×B)
标量三重积的轮换不变性
A×(B×C) = B(A·C) − C(A·B)
BAC-CAB 法则
(A×B)·(C×D) = (A·C)(B·D) − (A·D)(B·C)
四重积展开
∇(fg) = f∇g + g∇f
梯度乘积法则
∇·(fA) = f∇·A + A·∇f
散度乘积法则
∇×(fA) = f∇×A + ∇f×A
旋度乘积法则
∇·(A×B) = B·∇×A − A·∇×B
混合积的散度
∇×(A×B) = A(∇·B) − B(∇·A) + (B·∇)A − (A·∇)B
叉积的旋度
∇×(∇×A) = ∇(∇·A) − ∇²A
矢量三重积展开应用于 ∇ 算子
∇·(∇×A) = 0
旋度必无散
∇×(∇f) = 0
梯度必无旋

积分定理

∮S A·dS = ∫V ∇·A dV
高斯散度定理
∮C A·dl = ∫S (∇×A)·dS
斯托克斯定理

适用条件：上述积分定理要求被积函数在积分区域内连续可微。 若区域内有奇点（如点电荷所在处），须先把奇点挖去再取极限，不可直接套用。

关于「无散」与「无旋」： ∇·A = 0 只说明场线没有起点和终点，不意味着场线闭合成环 （A = ẑ 即处处无散，但场线是无限长直线）。 同理 ∇×A = 0 时环流为零、可写为 ∇ψ， 这两个结论都额外要求区域单连通——有洞的区域存在反例。

曲线坐标算子（附录 B）

直角坐标 (x, y, z)

∇²ψ = ∂²ψ/∂x² + ∂²ψ/∂y² + ∂²ψ/∂z²
d³r = dx dy dz

球坐标 (r, θ, φ)

∇²ψ = (1/r²)∂r(r²∂rψ) + (1/r²sinθ)∂θ(sinθ ∂θψ) + (1/r²sin²θ)∂²φψ
d³r = r² sinθ dr dθ dφ
∇ψ = ∂rψ r̂ + (1/r)∂θψ θ̂ + (1/rsinθ)∂φψ φ̂
∇·A = (1/r²)∂r(r²Ar) + (1/rsinθ)∂θ(sinθ Aθ) + (1/rsinθ)∂φAφ

柱坐标 (ρ, φ, z)

∇²ψ = (1/ρ)∂ρ(ρ ∂ρψ) + (1/ρ²)∂²φψ + ∂²zψ
d³r = ρ dρ dφ dz
∇ψ = ∂ρψ ρ̂ + (1/ρ)∂φψ φ̂ + ∂zψ ẑ

坐标符号约定：本书柱坐标的径向坐标统一记为 ρ（不是 r）， 以避免与球坐标的 r 混淆。图注与公式中若见 r 作柱径向， 应理解为 ρ。
