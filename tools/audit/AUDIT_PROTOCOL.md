## 二、审查目标

三条主线，缺一不可：

- **A. 错误查找**：物理错误、数学/推导错误、量纲错误、数值错误、符号与约定不一致、
  交叉引用/公式编号错误、术语不一致、事实性错误（常数值、历史陈述）。
- **B. 初学者适用性**：是否可自学。关注：前置知识缺口、跳跃步骤、
  未定义符号的首次使用、术语未解释、难度曲线、例题是否真正「分步」、
  是否有「显然/易得/不难看出」式跳过、练习题是否有解答、自测答案是否齐全。
- **C. UI 设计**：`html/` 六页面的信息架构、视觉系统、可用性、与教材内容的一致性。

## 三、硬性纪律（违反即返工）

1. **一切结论必须锚定到源码行号**（`electrodynamics_textbook_v2.tex` 的行号），
   或 `html/*.html` 的文件名+行号。禁止「大概在第三章」这类定位。
2. **不得轻信本书自述**。任何「本书已统一约定 X」的说法，必须在正文中抽查 ≥3 处验证。
3. **数值/公式结论必须独立复算**。可用 Python（已装 numpy 2.5.3 / scipy 1.18.1 / sympy 1.14.0）。
   须在报告中给出复算代码或命令与输出。
4. **区分「错误」与「风格偏好」**。风格问题单独归类，不得混入错误清单。
5. **不得虚报**。若某处检查后未发现问题，写「已检查，未发现问题」，
   **严禁为凑数编造问题**。宁少而真，不多而假。
6. **每条问题给出可直接落地的修正文本**（中文原文 + 建议改法），不要只说「此处有误」。
7. 报告用**中文**撰写。

## 四、问题分级

| 级别 | 判据 |
|------|------|
| **blocker** | 结论错误会误导读者建立错误物理图像；或公式错误导致后续推导/习题系统性错误 |
| **high** | 明确的公式/符号/数值错误，或关键概念表述错误 |
| **medium** | 推导跳步导致初学者无法跟进、交叉引用错误、术语前后不一致 |
| **low** | 笔误、排版、文字表述、风格不一致 |

## 五、问题编号规范

每条问题使用唯一 ID：`<模块>-<序号>`，例如 `CH07-03`、`EX-12`、`UI-05`、`BEGIN-07`。
字段必须齐全：

```
ID: CH07-03
级别: high
位置: tex 第 5612 行（§7.1.5，p.104）
原文: <逐字引用，必要时截断>
问题: <为什么错，错在哪一步>
证据: <复算代码/推导过程/教材对照>
修正: <建议的替换文本>
```
